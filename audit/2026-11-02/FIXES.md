## Результаты проверок

- **62 backend-теста на SQLite** — пройдены.
- **Те же 62 backend-теста на PostgreSQL 16** — пройдены. В CI добавлена матрица обеих БД.
- **30 frontend-тестов** — пройдены, включая 16 новых проверок компонентов/навигации/хранилища.
- Ruff, форматирование, `uv lock --check`, TypeScript и production-сборка Vite — пройдены.
- API и web Docker-образы собраны; отдельный Compose-стенд успешно запущен, `/api/health` — 200.
- Сценарий с 60 игроками — **41/41**. Проверки ожидаемого счёта и одинаковых мест в исходном сценарном скрипте исправлены.
- Дополнительный smoke проверяет, что NaN отвергается, корректный ответ после него сохраняется и отчёт доступен; проверено ограничение входа через Nginx.

## Изменения запуска

Для backend теперь обязателен случайный `JWT_SECRET` не короче 32 символов; пример генерации и настройка `backend/.env` описаны в [README](../../README.md). Новый frontend рассчитан на Node.js 22.12+ в ветке 22 либо 24.x. Для доступа к dev-серверу с телефона используется явный `npm run dev -- --host`.

В Docker доверие к forwarded-заголовкам используется с внутренним API, порт которого Compose не публикует; Nginx устанавливает X-Forwarded-For из реального адреса своего клиента. Прямой запуск uvicorn не получает этого расширенного доверия автоматически.

Модель данных не менялась, миграция существующей БД для этих исправлений не нужна. Для применения к запущенному серверу требуется перезапуск; исходное ограничение MVP о хранении активных игр в памяти процесса сохраняется. Долговременное восстановление активных игр и многопроцессный режим в эти изменения не входят.
